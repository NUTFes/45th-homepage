# ADR 0001: 企画の開催日時とタイムスケジュール掲載設定を分ける

- Status: Accepted
- Date: 2026-08-18

## Context

企画担当者は来場者向けの企画内容、マップ上の場所、開催日時を登録する。一方、タイムスケジュール担当者は、確定した各開催日時をタイムスケジュール上の会場へ割り当てる。両者を1レコードで編集すると、担当範囲と入力手順が分かりにくく、企画ページの公開まで会場割り当てに依存してしまう。

## Decision

programs.scheduleItems を開催日時の正本とする。Program保存後、各配列行のIDに対応する timetable-listings を自動作成・同期する。掲載設定では会場グループと会場だけを編集できる。

開催日、天候、開始・終了時刻が変わった行は会場割り当てを解除して再確認を求める。行の並び替えでは配列行IDが変わらないため割り当てを保持し、削除した行に対応する掲載設定は削除する。

企画一覧・詳細は公開済みProgramの開催日時とマップ情報を表示し、掲載設定の有無に依存しない。将来のタイムスケジュールは、公開済み企画、有効な会場マスタ、会場設定済みの掲載設定が揃ったものだけを対象とする。

## Consequences

- 企画担当者とタイムスケジュール担当者の編集画面と責務が分かれる。
- 開催日時の変更後に誤った会場で掲載されることを防げる。
- Program配列行IDと掲載設定の複合一意制約、および同一トランザクション内の同期が必要になる。
- 公開タイムスケジュールは今回の対象外であり、/schedule は未公開のままとする。
