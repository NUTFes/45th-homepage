# Issue #244 マップ画像挿入 実装手順書

## 目的

マップページの仮表示を `public/image/map` に配置済みの画像へ置き換え、モバイルと PC の両方で選択したマップを確認できるようにする。

関連 Issue: <https://github.com/NUTFes/45th-homepage/issues/244>

## 前提と対象範囲

- 実装は最新の `origin/main` から分岐する。マップ画像は Issue #242 で追加済みである。
- 対象は `src/modules/map` と、画像の表示方法を切り替える `src/components/ui/MapFrame.tsx` とする。
- Payload CMS のスキーマやデータは変更しない。
- 右側の PC メニューとモバイルのアコーディオンから「スタンプラリー」を削除する。
- 「制作物」配下から「制作物(講義棟　1F)」を削除し、「制作物全体」は残す。

## 実装手順

1. `mapMenuData.ts` の各選択項目に画像パスと内容を表す代替テキストを追加する。
2. 同じファイルから「スタンプラリー」と「制作物(講義棟　1F)」を削除する。
3. 選択 ID から画像情報を取得できる共通関数を追加し、PC 表示とラベル取得で利用する。
4. `MapPageView.tsx` で、全体マップと各アコーディオン項目の画像情報を `MapFrame` に渡す。
5. `MapPcSection.tsx` で、右側メニューの選択に連動してタイトルと画像を切り替える。
6. 地図の端にある凡例や文字を切らないため、`MapFrame` に画像全体を収める表示オプションを追加し、マップページだけで使用する。
7. `next/image` の `fill` を使う箇所では、親要素の相対配置と `sizes` を指定してレスポンシブ画像を配信する。

## 動作確認

1. `pnpm run quality:check` を実行し、フォーマット、lint、フォント、型検査が成功することを確認する。
2. Docker 開発環境を起動し、モバイル幅で `/map` を表示する。
3. 最初に全体マップが表示され、各アコーディオン内に対応する画像が表示されることを確認する。
4. PC 幅で右側メニューを順に選び、タイトルと画像が対応して切り替わることを確認する。
5. 両方の表示で「スタンプラリー」と「制作物(講義棟　1F)」が存在しないことを確認する。
6. 各画像の四辺、凡例、文字が切れず、画像の縦横比が崩れていないことを確認する。
